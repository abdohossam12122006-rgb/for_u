# حِتّة ليك

موقع شخصي لشخص واحد. مش صفحة عامة — **مكان**.

اتعمل عشان حد بيمرّ بفترة تقيلة، وعشان الكلام الحقيقي مش دايمًا بيلاقي مكان يقوله فيه.

> **نبرة المحتوى:** مباشرة وواقعية، من غير مبالغة عاطفية. مفيش قلوب ولا رموز عاطفية في الواجهة، والكلام بيقول المعلومة أو الموقف من غير وعود كبيرة.

---

## إيه اللي في الموقع؟

| القسم | إيه اللي بيعمله |
|---|---|
| **دخول** | شاشة واحدة الأول: «خُد نفس. وبعدها ادخل». بتظهر مرة في كل جلسة. |
| **خُد نفس** | تمرين تنفس (٤ شهيق · ٤ وقفة · ٦ زفير) بحركة بصرية، وتمرين تأريض ٥·٤·٣·٢·١، وقايمة سريعة «لما تكون مش قادر». |
| **١٦ يوم** | حِتّة صغيرة بتقول له إن الفترة اللي عرفته فيها مش مقياس، وإن اللي هو فيه مش تقصير. |
| **الرسالة الطويلة** | ظرف مقفول بيتفتح لما يدوس عليه — رسالة كاملة بصوت صاحبه، مكتوبة مخصوص له. |
| **رسايل صغيرة** | ٨ رسايل قصيرة لكل حالة: لما يصحى مش قادر، لما يحس إنه لوحدي، لما يفتكر إنه مش كفاية، لما حد يزعّله… وزر «افتح لي رسالة» عشوائي. |
| **الحِتّة اللي ليك** | المكان اللي بيكتب فيه كل اللي مضايقه — **مقفول بباسورد هو اللي بيحطه**، ومحدش يقدر يفتحه (ولا اللي عمل الموقع). |
| **صغيّرات** | ٨ حاجات صغيرة على قد الإيد، بتترجع لصفر كل يوم، مع شريط تقدّم. |
| **دليل النجاة** | ٦ حالات عملية (مش قادر تنام / تاكل / تقوم / بتعيّط / حد مضايقك / محتاج حد) بإجابات قصيرة من غير وعظ. |
| **أغاني جورج وسوف** | ٦ اختيارات (كلام الناس، لسه الدنيا بخير، الله كريم، صابر وراضي، انت غيرهم، ميكس طويل) بتتشغّل من يوتيوب جوه الصفحة، مع لينك احتياطي. |
| **مساعدة** | أرقام الدعم النفسي في مصر + زر «مش قادر؟» ثابت في كل الصفحة بيفتح خطة سريعة للتهدئة. |
| **ظبط الأسماء** | تكتب اسمك واسمه مرة واحدة، والكلام في الموقع يبقى باسمهم. |

## إزاي تفتحه

الموقع كله ملفات ستاتيك — مفيش خادم، مفيش بناء، مفيش حساب.

```bash
# أسهل طريقة: افتح index.html في المتصفح
# أو شغّل سيرفر محلي
python3 -m http.server 8000
# وبعدين افتح http://localhost:8000
```

تحتاج ترفعه على أي استضافة ستاتيك (GitHub Pages / Netlify / Vercel) وتدّيه اللينك لصاحبك.

## الخصوصية والأمان — بالتفصيل

مهم تكون عارف بالظبط إيه اللي بيحصل:

- **مفيش سيرفر.** مفيش أي بيانات بتطلع من المتصفح، ومفيش تحليلات ولا تتبع ولا إعلانات.
- **الحِتّة (الجورنال)** بتتخزن في `localStorage` على جهاز صاحبك.
- الكلام **متشفّر**: المفتاح بيتولّد من الباسورد بـ `PBKDF2` (١٦٠٠٠٠ دورة، SHA-256)، والتشفير `AES-GCM` بمفتاح ٢٥٦-بت. الباسورد نفسه مش بيتخزن أبدًا في أي مكان.
- يعني: **لو نسي الباسورد، مفيش استرجاع** — لا انت ولا أي حد. عشان كده في تلميح اختياري بيظهرله في شاشة القفل.
- في **نسخة احتياطية وتصدير** لكل اللي كتبه في ملف Markdown، وزر مسح كامل.
- الحِتّة بتقفل لوحدها بعد ١٠ دقايق من السكون، وكمان بعد دقيقة ونص لو ساب المتصفح في الخلفية.
- لحظة القفل، النص المفكوك بيتشال من الصفحة نفسها (مش بيتخفي بس)، فمفيش حد يقدر يقراه من الـ DevTools.
- الطباعة والتصدير بيحصلوا على الجهاز نفسه.

> ملاحظة صغيرة: البيانات مشفّرة ومربوطة بالجهاز. لو مسح بيانات المتصفح، الحِتّة هتتمسح — عشان كده زر التصدير موجود.

## إزاي تغيّر حاجة

| عايز تغيّر | المكان |
|---|---|
| الأغاني | `index.html` → قسم `#songs` → غيّر `data-video` بمعرّف فيديو يوتيوب، والاسم والوصف. |
| الرسالة الطويلة | `index.html` → `#letter` → `.env-inner`. |
| الرسايل الصغيرة | `app.js` → كائن `letters` (المفتاح = الـ`data-letter` في الكارت). |
| جُمل «جرعة النهاردة» | `app.js` → مصفوفة `quotes`. |
| الدليل | `index.html` → `#accordion`. |
| أرقام المساعدة | `index.html` → قسم `#help` (وحدّثها لو تغيّرت). |
| الألوان والخطوط | `styles.css` → متغيرات `:root` في الأول. الخطوط محلية في `fonts/` — مفيش حاجة بتحمّل من جوجل. |
